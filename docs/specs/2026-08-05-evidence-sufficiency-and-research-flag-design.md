# 근거 충분성·수집 플래그·웹 조사 반복

- 작성일: 2026-08-05
- 상태: 승인 (관련 출처 URL **3개**)
- 관련: `docs/plans/agentic-research-rag/00-preimplementation-decisions.md` D5

## 문제

벡터 인덱스에 **무관한 청크가 하나라도** 있으면 `sufficient=True`가 되어 웹 조사를 건너뛰었다.  
그 결과 “근거 준비됨”이 떠도 주제에 맞는 자료가 없고, 대화 품질도 나아지지 않았다.

## 결정

### 1. 충분성

1. 인덱스에서 후보 청크를 검색한다.
2. `score = 1/(1+distance)` 가 **0.45 이상**인 청크만 관련 자료로 본다.
3. 그중 **서로 다른 `canonical_url`(없으면 `source_url`)이 3개 이상**이면 충분하다.
4. 청크 수와 무관하다. 한 URL에서 조각이 많아도 출처 1개로 센다.

상수:

- `MIN_RELEVANCE_SCORE = 0.45`
- `MIN_DISTINCT_RELEVANT_URLS = 3`

### 2. 웹 조사 반복

한 번의 조사 실행 안에서:

1. 인덱스 검색 → 충분하면 웹 생략, `COMPLETED`
2. 부족하면 웹 검색·수집·인덱싱 후 재검색
3. 충분해지거나, 더 이상 새 자료를 못 모으거나, 라운드 상한(`MAX_WEB_EXPAND_ROUNDS = 3`)에 닿을 때까지 반복

대화 턴마다:

- 아래 수집 플래그가 True이고, 원고당 조사 횟수 상한(5) 미만이며, **아직 충분하지 않으면** 새 조사를 시작한다.
- 이미 관련 URL ≥ 3이면 플래그를 세우지 않는다(조사 횟수 낭비 방지).

### 3. 근거 수집 플래그 (요청마다)

매 사용자 메시지에서 라우터 `UserAction` + 주장 휴리스틱으로 판별한다.

| 조건 | 플래그 |
| --- | --- |
| `feedback` / `outline` / `generate_document` / `refuse` / `opening` | False |
| `say` + 컨셉 허용 + 일반론·수치 휴리스틱 + 아직 근거 부족 | True 가능 |

“피드백 해주세요”, “문서화/탈고 해주세요”는 의도 분류 결과로 False다.  
텍스트에 수치가 섞여 있어도 feedback/문서 요청이면 수집하지 않는다.

### 4. 완료 표시

- `COMPLETED` / 화면 “근거 준비됨”: 관련 URL ≥ 3
- `PARTIAL`: 관련 청크는 있으나 URL < 3
- `FAILED`: 관련 자료 0

## 비범위

- 서비스 성장 Judge 문제집 기준 변경
- 임베딩 모델 교체
- 원고당 조사 횟수 상한(5) 변경
